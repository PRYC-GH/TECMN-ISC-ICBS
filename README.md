# 📊 Informe Académico Web: ITM - TecNM Morelia

Sitio web informativo y de investigación enfocado en la presentación y análisis estructurado de carreras del **Instituto Tecnológico de Morelia (ITM - TecNM)**, destacando perfiles, retículas, aplicaciones prácticas y enfoques sustentables.

---

## 🚀 Estructura del Proyecto

El sitio está desarrollado con una arquitectura ligera de archivos estáticos HTML/CSS autocontenidos (optimizada para rendimiento y compatibilidad), dividida en los siguientes módulos:

*   **`index.html`:** Página principal con la identidad visual institucional del TecNM (tonos rojos y amarillos), menú superior fijo con navegación por anclas internas, resumen ejecutivo de las carreras, tabla de proyectos prácticos y apartados de sustentabilidad.
*   **`isc.html`:** Subpágina dedicada a la **Ingeniería en Sistemas Computacionales**, diseñada con una paleta de colores grisáceos tecnológicos. Contiene el desglose de ingreso, retículas por semestres, extras (servicio social/residencias), perfil de egreso y referencias bibliográficas/institucionales.
*   **`icbs.html`:** Subpágina de la segunda carrera institucional, estructurada con un diseño en tonos azul oscuro sobrio y con la misma jerarquía de apartados y referencias.

---

## 🛠️ Tecnologías y Enfoque

*   **Frontend:** HTML5 semántico y CSS moderno (con integración limpia mediante CDN para estilos responsivos y dinámicos).
*   **Diseño:** Interfaz modular basada en tarjetas (*cards*), tablas de datos estructuradas y paletas de colores institucionales personalizadas.
*   **Hardware / Entorno de desarrollo:** Diseñado y optimizado bajo flujos de trabajo eficientes, sin dependencias locales pesadas ni frameworks de servidor complejos.

---

## 🌐 Despliegue (GitHub Pages)

Este proyecto está configurado para ejecutarse de manera estática mediante **GitHub Pages**. Una vez subidos los archivos a la rama principal (`main`), el sitio puede visualizarse públicamente de forma automática a través de la URL de GitHub Pages configurada en el repositorio.
